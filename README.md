# Python Util Scripts
[Decrypt Captured Packets](https://github.com/GadgetXl/python-util/blob/main/decrypt_captured_packets.py): Decrypts AES-128 encrypted packets and saves them to server_to_client.txt if the source IP matches the target IP; otherwise, saves them to client_to_server.txt

[Height Fix](https://github.com/GadgetXl/python-util/blob/main/height_fix.py): Takes a .bin heightmap, fills blank areas using nearest neighbor values, and outputs the corrected .bin file.

[Pre Compute](https://github.com/GadgetXl/python-util/blob/main/pre_compute.py): Precomputes the .bin walkable map for later use in pathfinding and exports the result to an .npz file.
